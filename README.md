# ligrivsstore

Gestionnaire de mots de passe du projet KEEPASS : applications Windows (avec extension Chrome et Edge) et Android, puis iPhone, iPad et Mac. Les coffres sont au format ouvert KDBX 4, chiffrés sur chaque terminal et synchronisés avec le serveur « coffre ».

Le jalon 0 (noyau, outil de recette, tests et intégration continue) arrive par la branche `jalon-0/fondations`.
